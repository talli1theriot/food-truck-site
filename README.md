# food-truck-site
## What changes at each breakpoint

- Phones: "menu cards" are stacked, "come see us" boxes are stacked
- From md (768px): "menu cards" have 2 side-by-side, "come see us" boxes are side-by-side
- From lg (992px): "menu cards" have 3 in a row, "come see us" boxes are side-by-side but stretched
